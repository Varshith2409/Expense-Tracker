# Expense Tracker 

An offline-first expense tracker that stores data locally in your browser (IndexedDB) and provides quick monthly insights with category totals and charts.

## Features
- ✅ Add expenses (date, amount, category, optional note)
- ✅ Edit / delete expenses
- ✅ Month navigation (YYYY-MM)
- ✅ Monthly budget + remaining / over-budget indicator
- ✅ Search + category filtering
- ✅ Totals by category table + bar chart
- ✅ Export / import JSON backup (full data restore)
- ✅ Clear a selected month’s expenses

## Tech Stack
- React 19 + TypeScript
- Vite
- Dexie (IndexedDB storage)
- Recharts (charts)

## Getting Started

### 1) Install
```bash
npm install
'''

### 2) Run locally
npm run dev
